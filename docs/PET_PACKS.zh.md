# Deeptop 互动宠物包开发指南

[English](PET_PACKS.md) | 中文

Deeptop Pet 使用固定图集格式，并在独立的透明置顶 WebView 中运行。宠物可以注视全局鼠标、跨应用和显示器拖动、记住最后一次可见位置，并响应点击、双击、长按、抚摸、空闲时间和当前任务状态。共享养成层保存饱食、心情和亲密度，提供喂正餐、喂点心、摸摸与陪玩；换宠物包只更换外观和动作，不会重置养成状态。第三方宠物包只有声明文件和图集，不能执行代码。独立窗口只接收有数量上限的活动列表：任务状态、会话标识与标题、确认原因、工具名、问题和选项等提醒卡字段，以及已完成会话最后一段助手回复的受限摘要；它不能读取完整历史、推理、文件内容、模型配置、工具结果、网络或 DSH Bridge。关闭“设置 → 宠物”总开关后，Tauri 会销毁整个宠物窗口及其中的动画任务。

`.deeptop-pet` 是 ZIP 型单文件制品。它与源码目录使用相同的三个根级文件，不接受脚本、CSS、HTML、网络地址、子目录、链接或未声明文件。直接分享、本地导入和后续宠物市场均使用这一种包。

## 可选源码模块

完整宠物系统由 `desktop-pets.feature.json` 描述。`npm run pets:remove:check` 只校验全部归属路径、主业务源码标记和依赖，不会修改工作区；`npm run pets:remove` 会一次移除渲染器、原生插件、设置入口、示例、制作工具、npm 与 Cargo 依赖、文档以及前端/Tauri 生成缓存。命令会先在临时 Cargo 项目中生成无宠物版 `Cargo.lock`，全部准备成功后才写入源码；标记、依赖或路径有任何缺失都会中止，不会猜测删除。剔除工具及清单最后删除自身。用户应用数据目录里已经安装的宠物包和养成数据会保留；需要恢复功能时从版本控制还原即可。

## 一句话交给 AI 制作

在支持 `hatch-pet` 工作流的 AI 编程环境中，可以直接发送一句话：`帮我做一只“戴黄色雨衣、会挥手的圆滚滚云猫” Deeptop Pet，作者 suakitsu；完成全部动作和注视方向校验，最后输出可分享的 .deeptop-pet，不要提交代码。` AI 应从描述中确定合适的名称和 id，通过 `$imagegen` 生成角色与全部动作，完成 8×11 图集的透明度、方向、连续性和视觉检查，再补齐 `pet.json`、`deeptop.json` 并调用本仓库打包器。这里的“做一个宠物”指完整可安装制品，不是单张角色图或未经检查的图集；如果环境没有该工作流，则按下文的源码目录和图集规范生成同样的三个文件。

## 从制作到市场

制作者先用宠物生成工作流或其他工具生成一张合规的 Deeptop Pet 动画图集，再复制任一 `examples/pets` 样品并替换宠物名称、描述和 `spritesheet.webp`。运行 `npm run pet:pack -- <宠物目录>` 后会得到一个可直接安装和转发的 `.deeptop-pet` 文件；在“设置 → 宠物”里安装一次即可完成本地验收。

未来的宠物市场不引入第二种安装格式。名称、预览图、标签、下载地址、文件大小和 SHA-256 等商品信息由市场目录单独保存，下载器只需把 `.deeptop-pet` 暂存到本地，并把目录中的 SHA-256 作为 `expectedSha256` 交给现有原生安装器；安装器会在写入宠物库前重新计算并拒绝不匹配的文件。这样市场入口可以独立启用或移除，本地导入、导出和已经安装的宠物不受影响。

## 养成状态与皮肤边界

养成数据由 Tauri 单独保存在 `pet-care-state.json`，不写入 `.deeptop-pet`，也不随导出包分享。饱食和心情按照实际经过时间缓慢变化，离线一次最多计算 24 小时；亲密度不会自动下降，也没有死亡或永久惩罚。关闭“养成互动”会暂停时间变化，但不影响宠物显示、Deeptop 任务提醒或已保存的数据。

单击宠物打开当前会话卡；卡片右上角的“照顾”可切换到养成面板。长按相当于摸摸，双击相当于陪玩。原生层会限制过量喂食、饥饿或高兴时继续陪玩，并持久化正餐、点心、摸摸和陪玩的独立冷却时间；任一动作后还有短暂的公共间隔，不能通过连续点击或重启窗口快速刷满数值。按钮直接显示剩余时间。喂食和互动先由原生层更新并原子保存共享状态，再请求当前皮肤播放已有的挥手或跳跃反馈；皮肤包不能修改数值规则、读写存档或注入食物逻辑。因此同一个包可以进入市场，也可以在完全关闭养成层时继续作为普通 Deeptop 桌宠使用。

## 源码目录

最小的 Deeptop Pet 只需要两个文件；可选的 `deeptop.json` 用于补充版本、作者、许可证和声明式互动：

```text
cloud-cat/
  pet.json
  deeptop.json        # 可选
  spritesheet.webp
```

`pet.json` 是 Deeptop Pet 清单：

```json
{
  "id": "io.github.your-name.cloud-cat",
  "displayName": "云猫",
  "description": "一只会回应点击和任务状态的云猫。",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

`deeptop.json` 是可选的安全扩展清单：

```json
{
  "kind": "deeptop-pet",
  "schemaVersion": 2,
  "runtimeProfile": "deeptop",
  "version": "1.0.0",
  "author": "Your Name",
  "license": "CC-BY-4.0",
  "interactions": [
    { "on": "tap", "play": "waving", "then": "idle", "cooldownMs": 350 },
    { "on": "doubleTap", "play": "jumping", "then": "idle", "cooldownMs": 500 }
  ]
}
```

省略 `deeptop.json` 时，Deeptop 仍可直接导入普通 Deeptop Pet，并使用默认互动、`1.0.0` 版本和未声明许可证标记。准备公开分享或进入市场时，应补全扩展清单。

## Deeptop Pet 图集

`spritesheet.webp` 必须是带透明通道的 `1536×2288` WebP，由 8 列、11 行 `192×208` 单元组成。使用中的单元必须包含可见像素，其余单元必须完全透明。

| 行 | 内容 | 使用列 |
| --- | --- | --- |
| 0 | 待机帧；第 6 列为正面中性帧 | 0–6 |
| 1 | 向右移动 | 0–7 |
| 2 | 向左移动 | 0–7 |
| 3 | 挥手 | 0–3 |
| 4 | 跳跃 | 0–4 |
| 5 | 失败 | 0–7 |
| 6 | 等待用户输入 | 0–5 |
| 7 | 正在执行任务 | 0–5 |
| 8 | 完成并等待审查 | 0–5 |
| 9 | 注视方向 0–7 | 0–7 |
| 10 | 注视方向 8–15 | 0–7 |

16 个注视方向从正上方开始，每格顺时针旋转 22.5°。Deeptop 仅在宠物待机且鼠标位于有效距离内时使用这些单元；逐帧 Canvas 和全局指针轮询均与 React 主界面状态树隔离。

## 互动与任务状态

`interactions` 最多 32 条，每条可使用以下事件：

- `pointerEnter`、`pointerLeave`；
- `tap`、`doubleTap`、`longPress`；
- `dragStart`、`dragEnd`；
- `idleTimeout`。

`play` 和 `then` 只能引用 `idle`、`running-right`、`running-left`、`waving`、`jumping`、`failed`、`waiting`、`running` 或 `review`。循环动作不能设置 `then`，冷却时间为 0–60000 毫秒。同一事件可以声明多个规则，运行时会从当前不在冷却期的规则中选择。

任务状态不由第三方清单伪造：Deeptop 主窗口按照“需要输入、阻塞、已完成未读、运行中”排列会话活动。未读的完成或失败项会保留到用户打开或继续对应会话；待处理的权限申请和 Agent 提问会保留到主业务处理完成。完成项只投影最后一条正式 `assistant/message` 的受限摘要，不投影推理、工具结果或更早消息。卡片可以打开所选会话、向会话排队发送快捷回复、允许一次或拒绝权限，以及直接回答单个问题；包含多个问题时会要求打开主窗口逐项回答。所有动作都先在原生层校验是否仍匹配所选活动，再交回主窗口复用原有的 DSH 请求链，宠物窗口本身不调用 DSH。

按住并拖动时，原生窗口跟随系统指针；拖动方向播放左右移动，松开播放落地跳跃。关闭“允许互动”后，包括提醒卡在内的整个窗口穿透鼠标，但任务状态动画和被动提醒仍然可见。

保存的位置使用物理桌面坐标，并且只在它仍与当前某个显示器重叠时恢复。显示器被移除或重新排列后，宠物会回到所选的主显示器角落；修改“初始位置”也会主动重置已保存位置。窗口移动事件会先防抖再写入位置文件，不会在每次鼠标移动时写磁盘。

透明宠物窗口支持 Windows、Linux 和项目当前的 macOS DMG 构建。macOS 透明窗口需要 Tauri 的 `app.macOSPrivateApi` 设置；启用该私有 API 的应用不能通过 Mac App Store 分发。Deeptop 当前提供的是未签名、未公证的 DMG，并非 Mac App Store 包。

## 构建单文件包

在 Deeptop 仓库根目录运行：

```shell
npm run pet:pack -- /path/to/cloud-cat
```

脚本会在源码目录生成 `io.github.your-name.cloud-cat-1.0.0.deeptop-pet`。也可以指定输出位置；只有显式传入 `--force` 时才会替换已有文件：

```shell
npm run pet:pack -- /path/to/cloud-cat /path/to/share/cloud-cat.deeptop-pet --force
```

打包器固定归档时间和条目顺序，因此相同源码会产生相同字节，并在完成时打印小写 SHA-256 和字节数，市场可直接记录它们用于完整性校验、缓存和去重。仓库中的 `examples/pets/whale-maid` 和 `sawatari-shizuku` 是完整样品。

## 导入、导出和移除

在“设置 → 宠物”中选择“导入宠物”，Deeptop 会通过原生文件选择器读取并完整校验 ZIP。相同 id 的包需要确认后才会替换。市场下载还可以向同一个安装命令提供期望 SHA-256；校验发生在写入之前。本地导入候选会返回实际 SHA-256 和字节数，方便后续制作器或市场复用。设置页只按需读取当前选中的宠物，并提供可点击的动画预览；关闭该设置页后会释放额外的预览数据。所有已安装宠物都可以逐字节原样导出分享或移除；删除当前宠物后会切换到剩余宠物，删除最后一个宠物后桌宠自动关闭。

宠物库存放在 Tauri 应用配置目录的 `pets` 子目录。单个无效包只产生隔离的加载警告，不会阻塞 Deeptop 启动、会话功能或 DSH 运行时。

## 格式与安全限制

- id 为 3–64 位小写字母、数字、点、下划线或连字符，首尾必须是字母或数字；
- 名称最多 80 字符，描述最多 500 字符；扩展清单中的 version 必须是 SemVer，作者最多 80 字符，许可证最多 120 字符；
- 图集解压后最多 10 MB，清单各最多 64 KB，整个包最多 12 MB；
- 包只能包含 `pet.json`、可选的 `deeptop.json` 和 `spritesheet.webp`，每个安装目录最多加载 64 个包；
- 打包器拒绝逃出源码目录的素材；原生安装器再次拒绝绝对路径、目录穿越、重复条目、链接和额外文件；
- 运行时不提供脚本、CSS、HTML、网络、文件访问或权限字段。

宠物市场和制作器应生成、预览和安装 `deeptop-pet` 制品。未来若增加骨骼或矢量动画，应使用不同的 runtime profile，不能改变现有格式。
